# 📖 Sobre o Projeto

Este projeto foi desenvolvido como parte das atividades práticas do curso de Desenvolvimento de Sistemas do SENAI.

O objetivo foi criar uma aplicação mobile simples utilizando **React Native com Expo**, permitindo validar o funcionamento da estrutura básica de um aplicativo móvel.

A aplicação apresenta uma tela inicial personalizada com a identidade visual do SENAI e um botão interativo que, ao ser acionado, exibe uma mensagem de confirmação informando que o aplicativo está funcionando corretamente.

Este projeto representa os primeiros conceitos de desenvolvimento mobile, incluindo:

- Estrutura de componentes;
- Estilização de interfaces;
- Eventos de clique;
- Exibição de alertas;
- Desenvolvimento utilizando Expo;
- Testes em dispositivos móveis.

---

# 🎯 Objetivos

- Desenvolver o primeiro aplicativo mobile utilizando React Native;
- Compreender a estrutura de um projeto Expo;
- Criar interfaces utilizando componentes nativos;
- Trabalhar com eventos e interações do usuário;
- Realizar testes em dispositivos Android.
